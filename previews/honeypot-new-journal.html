Recreate the process

My step by step walkthrough

  1. Create the Windows 10 Azure VM and explain the network setup.
  2. Send Windows Security events through Azure Monitor Agent and a data collection rule to Log Analytics and Sentinel.
  3. Make three failed sign in attempts to the employee account.
  4. Find Event ID 4625 with KQL and review the login details.
  5. Group repeated attempts and create a Sentinel analytics rule.
  6. Enrich source IPs with the geoip watchlist and show approximate locations in the map.json workbook.
  7. Review the results, troubleshoot, and clean up the lab.

This is my process. You can adapt it for your own learning environment.
