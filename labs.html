Security Operations • Cloud Security

Cloud-Based SOC Monitoring & Threat Detection

Built and tested a cloud-based security monitoring environment using Microsoft Azure and Microsoft Sentinel to detect unauthorized login attempts and brute-force activity.

Security Problem Visibility into unauthorized authentication attempts and suspicious login activity
Detection Windows Event ID 4625 and KQL-based monitoring
Environment Microsoft Azure + Windows virtual machine
Outcome Security monitoring, detection logic, incident visibility and tuning
Azure Microsoft Sentinel KQL Log Analytics SIEM Event 4625
