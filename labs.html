Security Operations / Cloud Security

Cloud-Based SOC Monitoring & Threat Detection

Built and tested a cloud-based security monitoring environment using Microsoft Azure and Microsoft Sentinel to detect unauthorized authentication activity. Windows security events were centralized for analysis, queried using KQL, and used to generate Sentinel incidents. Detection logic was then refined to improve alert quality.
