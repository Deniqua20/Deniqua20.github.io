Azure Cloud Security Monitoring

I deployed Microsoft Sentinel and configured a Log Analytics workspace in Azure. This project focused on building the foundation for centralized security logging and reviewing how that supports audit visibility.

1. Prepare the lab environment

Follow the Azure environment requirements for the SentinelDeploy exercise documented in my project.

2. Configure the workspace

Create the Log Analytics workspace that will provide the centralized logging foundation.

3. Enable Microsoft Sentinel

Deploy Sentinel with the workspace and review the available monitoring capabilities.

4. Review connectors and readiness

Review the data connectors and configuration needed for log ingestion. Document deployment and ingestion readiness.

5. Connect the work to governance

Explain how centralized logging supports accountability, future monitoring, and audit visibility.
