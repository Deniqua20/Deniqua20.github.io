Security operations / Project overview

Cloud-Based SOC
Monitoring & Threat Detection.

A cloud-based security monitoring environment for unauthorized login attempts and brute-force activity.

Microsoft AzureMicrosoft SentinelKQLLog Analytics

The environment

I built and tested a cloud-based environment using a Windows virtual machine in Microsoft Azure, Windows Security Logs, Log Analytics, and Microsoft Sentinel. The monitoring focus is failed authentication activity, including Windows Event ID 4625.

Monitoring architecture

  1. Azure Windows VMGenerate and observe security events.
  2. Windows Security LogsCollect authentication activity and failed logon events.
  3. Log Analytics + SentinelCentralize logs for security monitoring.
  4. KQL detectionIdentify failed authentication patterns.
  5. Analytics rule + incidentTurn detection logic into security visibility.
