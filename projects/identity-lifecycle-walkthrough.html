Automated Identity Lifecycle Lab

I started with manual onboarding, role changes, and offboarding in Microsoft Entra ID. Then I built a pipeline that takes a simulated termination event through Logic Apps, Azure Automation, and Microsoft Graph.

1. Build the manual foundation

Use test accounts to practice creating users, assigning access, moving users between roles, and disabling accounts.

2. Create the Automation account

Create the Azure Automation account and enable its system assigned managed identity.

3. Configure Graph access

Grant the lab managed identity the Graph permissions documented in the source write up. Review the permissions against the actions your runbook needs.

4. Create the runbook

The Invoke-JMLOffboard runbook accepts a user principal name, authenticates with managed identity, and performs the offboarding actions through Graph.

5. Connect the Logic App

Use an HTTP request trigger to pass the test user principal name to the runbook, then add the completion notification.

6. Test and validate

Trigger the workflow for a test account. Check Logic App run history, runbook output, account state, memberships, audit logs, and notification delivery.
